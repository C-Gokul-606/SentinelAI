
# 🛡️ SentinelAI

### AI-Powered Spam & Suspicious Message Detection

SentinelAI is a machine learning-based threat analysis tool that analyzes SMS and text messages to identify potentially suspicious or spam content.

It combines **Natural Language Processing (NLP)** with **TF-IDF feature extraction** and **Logistic Regression** to classify messages, estimate risk, and highlight suspicious communication patterns.

## ✨ Features

- 🔍 Message-level threat analysis
- 🤖 Machine learning-based classification
- 📊 Spam probability and threat scoring
- 🚨 Low / Medium / High risk classification
- 🧠 Explainable suspicious-pattern detection
- 🔗 Suspicious URL detection
- ⚠️ Urgency-language detection
- 💳 Financial-request detection
- 🔐 Credential-request detection
- 🎁 Prize/reward pattern detection
- 🌑 Minimal cybersecurity-focused interface
- ⚡ Fast inference with a lightweight ML pipeline
